Vera was originally an AI chat app. Basically chatgpt.com except you can use any model. I'm not pivoting it away from AI and towards being a communications app. The long term goal is to be a decentralized, easily self-hostable messaging & email platform.

This legacy folder contains the old web app and db that were used for the AI chat app. They may serve as a reference for certain features that I want to include in the new Vera, but they are intentionally put off to the side so that they are not integrated into the new project in any physical way.

I repeat, the code in this folder is meant to serve solely as a **REFERENCE**. New things should not be built in here.
